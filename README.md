# 🌐 Exercício 01 — HTML

Meu primeiro exercício desenvolvido durante meus estudos de Desenvolvimento Web.

## 📌 Sobre o projeto

Este projeto foi criado para praticar os conceitos iniciais de HTML e entender a estrutura básica de uma página web.

## 🛠️ Tecnologias utilizadas

* HTML5

## 🎯 O que pratiquei

* Estrutura básica do HTML
* Tags HTML
* Títulos e textos
* Organização do conteúdo
* Estrutura de uma página web

## ▶️ Como executar

Basta abrir o arquivo `index.html` em qualquer navegador.

## 📚 Objetivo

Este projeto faz parte da minha jornada de aprendizado em Desenvolvimento Web e serve como prática dos conceitos básicos de HTML.
